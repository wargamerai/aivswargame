# 孤高の信長：一五七〇 — Webゲーム試作

スマートフォンとPCのブラウザーで遊べる、インストール対応の静的Webゲームです。ゲームの状態は現在のブラウザー内に保存されます。

## 起動

`index.html` をブラウザーで開いて動作を確認できます。ホーム画面への追加とオフライン対応を使うには、HTTPSで配信してください。サーバーへ公開すると、同じURLをスマートフォンやPCから開けます。

## 差し替え箇所

- 地図：提供された盤面の地理配置をもとに、中国地方・瀬戸内を左、近畿を中央、北陸を上、東海・甲信を右に配置。瀬戸内海・四国・淡路島を分け、海岸線・簡略化した領域境界・街道を描画します。領域の大小差も反映し、地図はスクロールと拡大縮小に対応し、上部の「地図／戦況」タブで戦略・参戦状況・自軍状況・ユニット一覧を切り替えます。右パネルは選択武将のコマンドと状況カードです。ユニットやカードの拡大プレビューにも対応。カードは中央に大きく表示してから処理し、指定武将を強調表示して地図中央へ寄せます。行軍時は移動可能エリアを強調表示します。
- ユニット画像：画像を `assets/units/` に置き、`game-data.js` の `unitImages` に武将名とファイルパスを追加。
- カード画像：画像を `assets/cards/` に置き、`game-data.js` の `cardImages` にカード名とファイルパスを追加。
- 今回受け取った16枚のカード画像に差し替え済み。裏面は `assets/cards/back.jpg`。
- 受け取った地図写真は `assets/maps/left.jpg` と `assets/maps/right.jpg` に保存。地図上の部隊位置を合わせていないため、現段階では盤面の背景には重ねていません。
- 能力値と軍勢駒数：`game-data.js` の `units`。
- 初期配置：`game-data.js` の各エリアの `initial`。
- 状況札：同ファイルの `cards`。
- 試作の勝敗条件：同ファイルの `goals`。
- 開始時の選択ルール：最初の状況カード選択、敗北条件を支配に変更、信長側武将の負傷。
- 見た目：`style.css`。

行軍時は地図上に矢印を表示し、行動・補充を画面上部に知らせます。戦闘は中央の画面で両軍とダイス判定を見せ、命中したダイスと損害を受けた駒に×印を表示します。駒数は重ねて表示します。支配地域は勢力ごとに色分けし、反信長側も武田・浅井・朝倉・一向一揆・三好・毛利・宇喜多・上杉などを区別します。参戦マーカーだけが進む場合も、移動元と移動先を大きく表示します。

地図や画像を差し替えるときは、ゲームのエリア名・座標・駒の対応も合わせて設定してください。ユニット駒は勢力ごとの色と役割、能力値を見分けやすくした仮デザインです。

## 試作版について

追記ルールに合わせ、戦略値、参戦トラック、反信長軍の参戦時期、勝敗条件をゲームに反映しています。提供された白地図を盤面画像として使用し、地図上の拠点にゲームの部隊を配置します。左右・上下にスクロールでき、＋／−ボタンで拡大縮小できます。初期配置と拠点数はまだ仮置きです。16枚の状況札と下書きユニット表の数値は `game-data.js` に反映済みです。カラー状況札と裏面はゲーム画面に設定してあります。

インターネット公開には静的サイトホスティングが必要です。この作業ではユーザーのホスティング先への公開は行っていません。端末間でセーブデータを同期する場合は、別途アカウントとサーバー保存の仕組みが必要です。

地図の武将名・部隊名は駒の下に表示します。能力値と駒数は開始オプションで表示を選べ、初期設定では非表示です。

操作コマンドとカードを引くボタンは地図上部にまとめ、山札と直前のカード、行動ログは地図下に配置しています。

各国の白地部分を盤面の国境線に沿った領域として取り出し、支配状態に応じて陣営色を重ねます。地名・国境線・街道は読み取れるように残しています。


### 状況カードの処理

織田信長・徳川家康・松永久秀・羽柴秀吉・明智光秀・柴田勝家・丹羽長秀のカードは、プレイヤーが操作します。徳川・松永と織田家臣は、反逆に達するまでは信長側として扱います。その他の大名カードは反信長側として自動処理し、戦闘を含む処理結果を表示します。いずれの場合も、結果画面の「確認して次へ」を押すまで次の状況カードは引きません。
